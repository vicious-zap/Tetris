# Neon Tetris

Un Tetris moderno construido con Canvas y JavaScript modular. Incluye las siete piezas, 7-bag, hold, ghost, wall kicks, niveles, combos, partículas, audio sintetizado y controles responsive.

## Ejecutar

Sirve el directorio con cualquier servidor estático, por ejemplo:

```bash
python3 -m http.server 4173
```

Abre `http://localhost:4173`.

## Pruebas

```bash
npm test
```
