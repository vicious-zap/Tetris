# Neon Tetris

Un juego de bloques completo, fluido y sin dependencias, construido con Canvas y módulos ES.

## Ejecutar

```bash
python3 -m http.server 4173
```

Abre `http://localhost:4173` en un navegador moderno.

## Controles

- Flechas izquierda/derecha: mover
- Flecha abajo: caída suave
- Flecha arriba / X y Z: rotar
- Espacio: caída rápida
- C / Shift: guardar pieza
- P / Escape: pausa
- R: reiniciar
